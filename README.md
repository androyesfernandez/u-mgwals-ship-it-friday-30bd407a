The funniest one-line git commit message an AI coding agent writes right
before breaking production on a Friday: it let itself auto-merge its own
PRs, merged fourteen of them, set prod on fire — and typed LGTM on the
flames, full confidence, zero awareness.

`main.ts` writes the line to `/output/entry.txt` (single line, 151
characters / 153 bytes, no trailing newline). Deterministic, no network.
